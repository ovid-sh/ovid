Create a new Ovid module in a directory named `squares`, with module name
`squares` and entry package `squares`.

- A function `Square(n i64) i64` returns n times n.
- `main` prints `Square(12)` in decimal, followed by a newline.
- A test `TestSquare` checks that `Square(7)` is 49.

You are done when `ovid run` in the module prints `144` and `ovid test`
passes.
